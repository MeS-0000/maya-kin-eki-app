# マヤをまなぶ｜マヤ暦 KIN番号検索サイト

生年月日からマヤ暦（ツォルキン暦）のKIN番号・太陽の紋章・ウェイブスペル・銀河の音・チャクラ系統・関係KIN各種・年廻りを診断するWebアプリ。

## 1. フォルダ構成

```
maya-kin-app/
├── index.html          ... ページ本体（フォーム・結果表示・年廻りセクション）
├── vercel.json         ... Vercelでの /kin パス対応（リライト設定）
├── css/
│   └── style.css       ... 全スタイル（白・グレー・ベージュ・ラベンダーの細線モダンデザイン）
└── js/
    ├── sealsData.js      ... 20の太陽の紋章データ（名称・キーワード）
    ├── sealIcons.js      ... 紋章アイコン画像の対応表・ラベルHTML生成
    ├── chakraConfig.js   ... 紋章とチャクラ系統(0〜4系)の対応表（編集はここだけでOK）
    ├── castleData.js     ... 52KINごとの「城」データ（第1〜第5の城）
    ├── mayaCalc.js       ... KIN番号にまつわる計算ロジック本体
    ├── yearForecast.js   ... 年廻り機能（対象年のKINと解説文の生成）
    ├── resultRenderer.js ... 診断結果エリア（ヘッドライン・関係性グリッド）のDOM描画
    ├── cycleTable.js     ... 人生の13年サイクル表の計算・描画
    ├── urlSync.js        ... URLパラメータ(?birthday=)とフォームの同期
    ├── shareActions.js   ... シェア(X/LINE)・印刷・URLコピーの挙動
    └── main.js           ... DOM要素の参照・イベント紐付け（エントリーポイント）
```

ビルド不要の素のHTML/CSS/JS（ESモジュール）構成。サーバーサイド処理は無いため、
そのまま静的ホスティングに置くだけで動作する。

## 2. 計算ロジック説明

### 基準日とKINの算出
1900-01-01 を基準点とし、そこからの経過日数（うるう日補正済み・後述）を260で割った
余りからKINを求める。基準点と定数 `KIN_OFFSET`（=208）は、以下の実例から逆算して
特定し、いずれも一致することを確認済み（`mayaCalc.js` 内のコメント参照）。
- 1983-11-07 = KIN238
- 2026-06-27 = KIN200
- 1984-03-28 = KIN120（うるう年の3/31・4/1のうるう日補正を検証した実例）

```
KIN = ((うるう日補正済みの経過日数 - KIN_OFFSET) mod 260) + 1
```

### うるう年の3/31・4/1の扱い
マヤ暦のKINカウントでは「うるう年の3/31と4/1は同じKIN番号」とする運用ルールがあるため、
単純な日数差では計算できない。`countLeapDayAdjustments()` で、基準日から対象日までに
発生した「うるう年の4/1」の回数を数え、その分だけ経過日数を差し戻す補正を行っている
（4/1を迎えるたびに、本来1日分進むはずのカウントを進めない＝3/31と同じ番号にする）。

### 太陽の紋章・銀河の音
```
紋章番号 = ((KIN - 1) mod 20) + 1   // 1-20
銀河の音 = ((KIN - 1) mod 13) + 1   // 1-13
```
20と13は互いに素なので、(紋章, 音) の組とKIN(1-260)は1対1に対応する（中国剰余定理）。
このため「紋章だけ変えて音は変えずに対応するKINを求める」計算（ガイドKIN等）は、
`getKinFromSealAndTone()` で総当たり的に逆引きしている。

### ウェイブスペル
13KINごとのまとまり。そのまとまりの先頭（音1）のKINの紋章が、ウェイブスペル名になる。

### チャクラ系統
20の紋章を5グループに分類（`chakraConfig.js` に分類データを分離して管理）。
紋章番号を5で割った余りで規則的に分類される（0系=5の倍数の紋章、1系=5で割って1余る紋章...）。

### 鏡の向こうKIN・絶対反対KIN
```
鏡の向こうKIN = 261 - KIN
絶対反対KIN   = KIN + 130 （260を超えたら260を引く）
```

### ガイドKIN・類似KIN・神秘KIN
いずれも「銀河の音は変えず、紋章だけを規則に従って変える」ことで求める。

- **ガイドKIN**：銀河の音によって紋章へのオフセットが決まる
  - 音 1,6,11 → オフセット 0（紋章はそのまま）
  - 音 2,7,12 → オフセット +11（紋章から数えて12番目）
  - 音 3,8,13 → オフセット +3（紋章から数えて4番目）
  - 音 4,9    → オフセット +15（紋章から数えて16番目）
  - 音 5,10   → オフセット +7（紋章から数えて8番目）
- **類似KIN**：類似紋章番号 = 19 − 紋章番号（0以下になったら+20）
- **神秘KIN**：神秘紋章番号 = 21 − 紋章番号

### 52KINサイクル（城）
KINを52個ずつ5分割し、第1〜第5の城として扱う。

### 年廻り機能
誕生月日はそのままに、対象年の日付でKINを再計算する（≒その年の誕生日のKIN）。
紋章・ウェイブスペルのキーワードと銀河の音から簡易な解説文をテンプレートで自動生成する。

#### 3月生まれのうるう年ズレ補正
うるう年補正（3/31と4/1が同じKIN）は3月の日付自身の年を対象にしないため、
生年と対象年でうるう年かどうかが食い違うと年廻りのKINが1ずれる。`yearForecast.js` の
`applyMarchLeapCorrection()` で以下の通り補正している。
- 3月生まれ・生年がうるう年でない人 → 対象年がうるう年のときだけKIN-1
- 3月生まれ・生年がうるう年の人 → 対象年がうるう年でないときだけKIN+1

## 3. デプロイ方法（Vercel）

1. このフォルダをGitリポジトリにする
   ```
   git init
   git add .
   git commit -m "init: maya kin app"
   ```
2. GitHub等にpushし、[Vercel](https://vercel.com/)で「New Project」からリポジトリをImport
3. Framework Presetは **Other**（静的サイト）を選択。ビルドコマンド・出力ディレクトリは空欄でOK
   （`index.html` がルートにあるため、そのまま配信される）
4. Deployを押すだけで公開完了。`vercel.json` により `/kin?birthday=1990-01-01` のような
   URLでも `index.html` が表示され、JS側でURLパラメータを読み取って自動診断される

### CLIでデプロイする場合
```
npm i -g vercel
vercel
```

## 4. 今後の拡張（会員機能など）について

- 計算ロジックは `js/mayaCalc.js` / `js/yearForecast.js` に完全分離されているため、
  将来的にNext.js等のフレームワークへ移行する場合もロジックをそのまま移植できる。
- 会員機能（診断履歴の保存等）を追加する場合は、現在の `renderResult()` 呼び出し箇所
  （`main.js`）にAPI保存処理を追加する形で拡張可能。
- チャクラ分類の見解が変わった場合は `js/chakraConfig.js` の `seals` 配列を編集するだけで反映される。
